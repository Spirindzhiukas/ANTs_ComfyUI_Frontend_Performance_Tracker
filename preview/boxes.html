Flat boxes, by box-detail level

The setting is box detail in the Tweaks tab, or window.__antsTracker.lowZoom.set({ boxDetail: "title" }). Every rectangle below is an operation the real paint path (lodPaintNode) issued, recorded from the harness canvas and replayed as SVG, in graph units, at the same numbers the code uses. LiteGraph's own node drawing (title text, sockets, widgets) is not reproduced — that is the drawing the flat path replaces. At 10% zoom each box is 20×10 css pixels on screen, so the picture is magnified 1.6×.
