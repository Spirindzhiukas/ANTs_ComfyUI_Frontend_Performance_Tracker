loader ComfyUI's own what is this?

No need to queue anything. Pick components above and MERD IT UP loads them through ComfyUI's own loaders, reads them, and frees them — your workflow's samplers never run. (If the graph has already run with a model wired to the node, that one wins: it is already in VRAM and it is what your samplers will use, so nothing is loaded twice.)  ·  diffusers is optional. Not every model has been added to diffusers — some arrive months after release, and vendor-specific or ComfyUI-only models never will. Without it the pipeline-default fields stay empty and say so; nothing else is affected.
